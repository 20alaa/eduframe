Student Registration GUI

Project Overview:
A Java-based desktop application providing a Graphical User Interface (GUI) for student registration. This project was developed as part of my coursework at **King Khalid University**.

Technical Highlights:
UI Components: Extensive use of `javax.swing` components including `JTextField`, `JRadioButton`, `JComboBox`, and `JCheckBox` to build a complete data entry form.
Layout Management: Implemented nested layouts using `BorderLayout` for the main frame and `GridLayout` (6x2) for precise form alignment.
Event Handling: Basic implementation of `ActionListener` to trigger a confirmation dialog (`JOptionPane`) upon form submission.
Styling: Custom background colors, padding (EmptyBorder), and layout dimensions to ensure a clean user experience.

Technologies Used:
Language: Java
Libraries: Java Swing, Java AWT
